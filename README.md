# Crystal Kizor | Personal Brand and Portfolio Hub

A unified personal brand landing page and portfolio hub for Crystal Kizor: architect, designer, entrepreneur, speaker, researcher, and civic founder. Built with Next.js App Router, TypeScript, and Tailwind CSS.

## The Practice Ecosystem

This digital hub unites seven distinct practices under a single personal brand:

1. Studio COKA: Architecture, interior design, and construction delivering climate-responsive environments in West Africa.
2. ELEvated: Contemporary furniture and product design rooted in African context, materials, and ideas.
3. The Effective Architect (TEA): Architecture education and media platform helping built-environment professionals learn and grow.
4. AKO Alliance: Expanding access to education and opportunity for children and young people.
5. Alive and Free: Christian youth movement focused on truth, healing, freedom, identity, purpose, and life in Christ.
6. Speaking Engagements: Keynotes and symposium dialogues on African cities, climate-responsive design, and entrepreneurship.
7. Crystal Kizor: Architecture, research, writing, media, and ideas directly under the personal brand.

## Key Design Principles

* Editorial Restraint: Inspired by the pacing of architectural monographs, avoiding generic corporate cards and artificial gradients.
* Single-Theme Consistency: Locked into an architectural limestone and iron palette with warm terracotta accents throughout the page.
* Audience Direction: Dedicated visitor pathway routing for clients, practicing architects, collectors, donors, youth, and conference organizers.
* Accessibility and Performance: Semantic landmarks, full keyboard focus states, WCAG AA contrast compliance, and responsive next/image optimization.

## Technology Stack

* Framework: Next.js (App Router)
* Language: TypeScript
* Styling: Tailwind CSS v4
* Typography: Geist and Geist Mono via next/font
* Icons: @phosphor-icons/react
* SEO: Structured JSON-LD metadata for Person and Organization

## Getting Started

1. Clone or open the repository.
2. Install dependencies:
   npm install
3. Start the local development server:
   npm run dev
4. Open http://localhost:3000 in your browser.

## Production Build

To test the production build:
npm run build
npm run start

## Deploying to Vercel

1. Push this repository to GitHub or GitLab.
2. Import the project into Vercel.
3. Vercel automatically detects Next.js.
4. Deploy with standard defaults (no special environment variables required for static preview).
